# Лабораторная работа №3

### Цель работы
Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также изучить принципы адаптивной вёрстки, правила контрастности и использование семантических тегов.

### Что было сделано

1. Архитектура и структура кода
* **Реструктуризация макета страницы**: Из основного контента удалена старая общая обёртка `.content`. Секции (`section`) выстроены вертикально друг за другом внутри тега `<main>`, а сам контент растянут на всю ширину экрана с отступами по бокам.
* **Интеграция навигации**: В шапку сайта (`<header>`) добавлен семантический тег `<nav>` с горизонтальным адаптивным меню. Элементы выровнены по центру шапки с помощью Flexbox.
* **Семантика по варианту**: Блок «Мои эко-привычки» оформлен с помощью семантических тегов `<article>`, а блок «Карта зелёных зон» внутри дашборда вынесен в семантический тег `<aside>`

2. Визуальное оформление и элементы
* **Flexbox-карточки**: Список личных привычек оформлен в виде полноценных карточек, выстроенных в горизонтальный ряд.
* **Индикаторы прогресса**: Внутрь каждой карточки добавлен кастомный прогресс-бар в процентах для наглядного отображения эко-привычек.
* **Grid-дашборд**: Создан современный двумерный дашборд «Эко-инициативы города», разделяющий блоки «Пункты приёма», «Акции» и «Карта зелёных зон» на 3 ровные колонки в один ряд.

3. Работа с CSS и анимацией
* **Адаптивность (Медиа-запросы)**: Добавлен блок `@media (max-width: 768px)`. При открытии сайта на планшетах и мобильных телефонах меню, карточки привычек и Grid-дашборд автоматически перестраиваются в одну колонку.
* **Контроль переполнения**: Использование `box-sizing: border-box` и адаптивных флекс-элементов позволило полностью предотвратить появление горизонтальной прокрутки.
* **Интерактивность и псевдоклассы**: Настроены и сохранены стили для состояний ссылок и кнопок (`:hover`, `:active`, `:focus`, `:visited`).
